# bookmyevent-mvp
Book My Event ek all-in-one event planning platform hai jo customers aur top event vendors ko ek hi jagah jodta hai. Chahe shadi ho, birthday party, ya corporate event—yahan aap aasani se best decorators, caterers, photographers aur venues dhundh kar book kar sakte hain. Humara maksad har event ko bina kisi tension ke memorable banana hai.
